⚙️ Leaderboard Admin

Server, Namen, Kategorien, Farben, Spieler und Events – direkt im Browser. ← Zur Statistikseite

🔑 Zugang

GitHub-Token (fine-grained, nur dieses Repo: Contents „Read and write“, für „Neu berechnen“ zusätzlich Actions „Read and write“). Er wird nicht gespeichert.

🌍 Server

Alles unten (Seite, Kategorien, Spieler) gilt für den gewählten Server. Farben und Events gelten für alle.

💬 Discord-Button (alle Server)

Link leer lassen = Button ausblenden.

Discord-Meldungen (Webhook)

Der Webhook-Link kommt als GitHub-Secret DISCORD_WEBHOOK (siehe Anleitung), nicht hierher. Hier wählst du nur, was gemeldet wird.

🏷️ Seite

🗂️ Kategorien dieses Servers

Häkchen = wird auf diesem Server angezeigt (so schaltest du eine Kategorie bei einem Server mit einem Klick zu oder ab). Namensfeld leer lassen = Standardname.

👥 Spieler

Anzeigename, Titel, eigene Farbe (↺ = Standardfarbe nach Platz) und Ausblenden.

🎨 Farben (alle Server)

📅 Events (alle Server)

Events werden sofort gespeichert, ohne „Speichern“ unten.

🏆 Erfolge

Erfolge erscheinen als Abzeichen im Spielerprofil und als Symbol neben dem Namen in der Gesamtwertung. Änderungen gelten nach „Speichern“ in der unteren Leiste.
